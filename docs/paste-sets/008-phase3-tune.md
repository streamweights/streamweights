Streamed path, forward. For models that don't fit: stream layers in order as inference does, but keep each layer's input activations (not outputs) for the whole micro-batch; LoRA parameters for all layers stay resident (they are small). Saved activations are micro-batch × seq × hidden × 2 bytes × layers; the memory budget from Phase 2.5 sizes the micro-batch so saved activations plus the ring plus working buffers stay under the 75% target; --grad-accum reaches the effective batch.
Streamed path, backward. Stream layers in reverse; for each layer, rebuild it from the ring slot, recompute its forward from the saved input, and compute the vector-Jacobian product for the LoRA parameters and the input gradient only (base weights get no gradient).
